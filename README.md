# Posterity Studies

Two static pages, served with GitHub Pages:

- `index.html`: What is Posterity Studies, the founding prospectus.
- `research-centers.html`: Relevant Research Centers and What Posterity Studies Adds, an interactive map of existing centers on the long-term future and the gap the field would fill.

Both pages are single files with no build step; the map loads d3 from cdnjs.
